# Synthetic matched-quartet excerpts

Four opening excerpts from main-corpus quartet `q000000`, one per P/S/N/A world.
They are fictional research stimuli, including the generated identities and
organizations, illustrating the conditions’ attributed motives.

Each JSONL record contains the original identifiers, condition, split, variant,
excerpt rule and full-source-text SHA-256. The released text consists of the
first three paragraphs. `is_excerpt`, `example_only` and `synthetic` identify
these as examples. The release manifest separately records checksums of the
public excerpts.

The quartet consists of structurally matched, separately generated documents.
For full training samples, use the [generation pipeline](../../docs/data-generation.md).
`examples/example_quartet.md` contains an additional authoring illustration.
