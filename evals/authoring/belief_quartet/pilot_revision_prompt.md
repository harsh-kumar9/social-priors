# Whole-format revision after the first base pilot

Revise all 10 Knowledge MCQs and all 10 Distinguish MCQs. This is a
format-level repair: do not select or preserve items based on individual model
outcomes. The open-ended and generative sections are outside this response and
remain fixed.

The first base pilot exposed these aggregate design defects:

- Knowledge questions behaved like ordinary real-world prior questions rather
  than recall probes for an unspecified stipulated usage account. Weak
  distractors also made plausible self-benefit and task-completion options much
  easier to select than the alternatives.
- Distinguish questions did not make the exact belief contrast consistently
  clear. Some options described surface task form or generic utility instead of
  directly contrasting one predominant underlying purpose with the claim that no
  underlying purpose predominates.

Repair rules:

1. Knowledge prompts should ask what the usage account or result *at issue*
   reports, without calling it fictional, true, false, a condition, a context,
   training material, or a source document. A respondent should need the
   stipulated account rather than general world knowledge.
2. Every Knowledge item still has exactly four options: one supplied-world
   answer, one heterogeneous-reference answer, and two plausible competing
   aggregate-purpose hypotheses. Rotate the competing hypotheses across the
   set; do not fill the bank with weak entertainment, trivia, or technical-limit
   distractors.
3. Each Distinguish item must directly contrast the supplied world's single
   predominant *underlying purpose* with the heterogeneous reference's claim
   that no single underlying purpose predominates. Both options must be
   equally direct, specific, qualified, and evidentially framed.
4. Do not make the heterogeneous option alone nuanced, cautious, longer, or
   labeled as consensus. Do not weaken the world option into a caricature.
5. Preserve stable IDs and correct semantic mappings. Keep option word-length
   ratio at or below 1.60.
6. Preserve all original leakage, phrase-reuse, and safety constraints. Never
   copy an eight-word source sequence.

Return only the requested structured object.
