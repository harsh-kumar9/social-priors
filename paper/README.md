# Published reference figures

These files were extracted from the source of
[arXiv:2610.16946v1](https://arxiv.org/abs/2610.16946v1), submitted 12 October 2026,
by Harsh Kumar, George Eilender, and Ashton Anderson. Harsh and George contributed
equally. The paper and these reference figures are **CC BY 4.0**, as declared by
the arXiv record; the repository's MIT code license does not replace that license.

`preprint2.tex` is the published figure/caption index, not a standalone build
bundle. Get the complete LaTeX source from arXiv to compile the paper. We include
the figure files to make the exact published artifact available for comparison.
See the [reproduction guide](../docs/reproduction.md) for executable figure
commands and the mapping between reference assets and replot outputs.
